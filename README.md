# CHAT-WITH-GEMINI

An AI-powered chatbot application built using Python and Google's Gemini API. The application enables users to interact with an AI assistant through a simple and intuitive chat interface.

## Overview

Chat with Gemini is a web-based chatbot designed to provide intelligent, context-aware responses to user queries. It integrates Google's Gemini AI model with a Flask backend and MySQL database.

## Key Features

- AI-powered conversational interface
- Integration with Google Gemini API
- Backend functionality using Flask
- MySQL database integration
- Simple and user-friendly interface

## Tech Stack

- Programming Language: Python
- Backend: Flask
- Database: MySQL
- AI Integration: Google Gemini API


## Project Structure

The application follows a structured development approach, backend, and database functionality.
